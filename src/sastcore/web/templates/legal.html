sastcore SAST

Privacidad y términos

sastcore analiza tu código para encontrar vulnerabilidades. Esto es lo que hacemos con él y lo que puedes esperar.

Privacidad de tu código

  • No se ejecuta: tu código solo se analiza de forma estática (se parsea y se buscan patrones). Nunca se ejecuta.
  • No se almacena: se procesa en un espacio temporal aislado que se borra al terminar la petición. No hay base de datos ni copias.
  • Sin telemetría: no usamos cookies de analítica ni rastreadores, y no compartimos datos con terceros.
  • Los informes se generan en el momento y no se guardan en el servidor, salvo que tú pulses «Compartir enlace» (ver abajo).

Por seguridad y operación, el servidor puede registrar metadatos técnicos de la petición (fecha, IP y código de respuesta) — nunca el contenido de tu código. Si pulsas «¿Falso positivo?» solo enviamos el nombre de la regla que se equivocó, sin tu código ni la ruta del fichero.

Enlaces compartidos (opcional)

  • Solo se guarda algo si tú pulsas «Compartir enlace». Por defecto no se almacena nada.
  • Se guarda únicamente el informe (los hallazgos), nunca tu proyecto completo. Ten en cuenta que un hallazgo incluye el fragmento de código de la línea afectada.
  • Caduca y se borra solo: el enlace deja de funcionar automáticamente pasado el plazo indicado al crearlo.
  • Quien tenga el enlace puede ver el informe: compártelo solo con quien quieras. No lo uses para código sensible.

Alcance y limitaciones

  • Lenguajes: JavaScript, TypeScript y Python.
  • Detecta: inyección (SQL y comandos), XSS, deserialización insegura, criptografía débil, secretos hardcodeados y flujos de datos peligrosos (taint), mapeados a CWE y OWASP.
  • Límite de subida: hasta 32 MB por análisis.
  • No sustituye una auditoría profesional: el análisis estático produce falsos positivos y falsos negativos. Revisa los resultados con criterio.

Términos de uso

  • El servicio se ofrece «tal cual», sin garantías de ningún tipo. Lo usas bajo tu responsabilidad.
  • Analiza solo código sobre el que tengas derecho a hacerlo.
  • No lo uses para atacar sistemas de terceros ni para abusar del servicio (aplican límites de tamaño y frecuencia).
  • Motor open-core bajo licencia Apache-2.0.

Contacto
